Help / FAQ

Installation, setup and answers to common questions.

01 / INSTALL

Install the application

Download the Apple silicon build for macOS 13 or later.
Follow the installation and first-launch instructions.

02 / CONFIGURE

Configure a model

No model is bundled.
Choose local Ollama, an OpenAI-compatible server or Codex CLI from the model chip.
See the model options.

03 / USE

Send a first request

Try “Which directory am I in?” or “Which process is using port 3000?”
Review the proposed commands and approvals before any change is made.

Frequently asked questions

Which Macs are supported?

The downloadable build targets Apple silicon (M1 and later) with macOS 13 or later.
No Intel build is available yet.
Check the download page for requirements.

Why does macOS warn me on first launch?

The current app is not signed or notarized.
See the first-launch instructions and verify your download against the published SHA-256 before opening it.

Do I need an account or an API key?

MacAIterm does not require its own account.
Local Ollama uses a model on your Mac.
Hosted services may require their own credentials; Codex CLI uses its own login.

The model is not responding.
What should I check?

Confirm the selected provider in the model chip.
For Ollama, check that Ollama is running and a model is installed.
For a compatible server, check the endpoint, model name, and credentials.
For Codex CLI, confirm it is installed and signed in.

Does my terminal output leave my Mac?

With local Ollama, model requests stay on your Mac.
With a remote provider, conversation context and command output go to that provider.
This includes output from SSH servers.
Read the privacy notes.

Why is the SSH monitor or file tree empty?

These tools need a separate non-interactive SSH connection, using key login or a shared connection from a session opened in the sidebar.
An ordinary password-only terminal connection may not provide that access.

Where are settings and history stored?

In ~/Library/Application Support/MacAIterm/.
Session history can be disabled in Settings and deleted per session.
The privacy page describes local storage.

How do I uninstall MacAIterm?

Quit the app and move it from Applications to the Trash.
To remove settings and history as well, remove ~/Library/Application Support/MacAIterm/.
Removing this folder permanently deletes that local data.

Is MacAIterm free?

MacAIterm is released under the MIT license.
Your chosen model provider may charge separately for its service.
