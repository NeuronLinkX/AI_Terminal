도움말 / FAQ

설치, 설정 방법과 자주 묻는 질문에 대한 답변.

01 / 설치

애플리케이션 설치

macOS 13 이상용 Apple 실리콘 빌드를 내려받으세요.
설치와 첫 실행 안내를 따르면 됩니다.

02 / 설정

모델 설정

모델은 포함되어 있지 않습니다.
모델 칩에서 로컬 Ollama, OpenAI 호환 서버, Codex CLI 중 하나를 선택하세요.
모델 옵션을 참고하세요.

03 / 사용

첫 요청 보내기

“현재 디렉터리가 어디인가요?”, “3000번 포트를 사용하는 프로세스가 무엇인가요?”처럼 요청해 보세요.
변경이 일어나기 전에 제안된 명령과 승인 내용을 확인하세요.

자주 묻는 질문

지원하는 Mac은?

내려받는 빌드는 macOS 13 이상의 Apple 실리콘(M1 이상)용입니다.
Intel 빌드는 아직 제공하지 않습니다.
요구 사양은 다운로드 페이지에서 확인하세요.

처음 실행할 때 macOS가 경고하는 이유는?

현재 앱은 서명과 공증을 하지 않았습니다.
첫 실행 안내를 보고, 열기 전에 공개된 SHA-256과 내려받은 파일을 대조하세요.

계정이나 API 키가 필요한가요?

MacAIterm 자체 계정은 필요 없습니다.
로컬 Ollama는 Mac에 있는 모델을 씁니다.
호스팅 서비스는 자체 인증 정보가 필요할 수 있고, Codex CLI는 자체 로그인을 씁니다.

모델이 응답하지 않아요.
무엇을 확인하나요?

모델 칩에서 선택한 제공자를 확인하세요.
Ollama는 실행 중인지, 모델이 설치되어 있는지 봅니다.
호환 서버는 엔드포인트, 모델 이름, 인증 정보를 확인하세요.
Codex CLI는 설치와 로그인 상태를 확인하세요.

터미널 출력이 Mac 밖으로 나가나요?

로컬 Ollama를 쓰면 모델 요청은 Mac 안에 머뭅니다.
원격 제공자를 쓰면 대화 컨텍스트와 명령 출력이 그 제공자에게 전달되며, SSH 서버의 출력도 포함됩니다.
개인정보 안내를 읽어 보세요.

SSH 모니터나 파일 트리가 비어 있는 이유는?

이 도구들은 키 로그인이나 사이드바에서 연 세션의 공유 연결을 쓰는 별도의 비대화형 SSH 연결이 필요합니다.
비밀번호로만 접속한 일반 터미널 연결에서는 이 접근이 안 될 수 있습니다.
SSH 가이드를 보세요.

원격 화면에서 AI 채팅은 어떻게 동작하나요?

AI 채팅은 원격 화면을 보거나 조작하지 못합니다.
요청은 SSH 셸의 명령으로 실행되고 결과가 채팅에 나옵니다.
그래서 “terminal 창을 열어줘”라고 해도 클릭하는 대신 명령을 실행합니다.
서버에서 작업하게 하려면 채팅 아래의 원격 스위치를 켜세요.
키보드 입력은 포커스가 있는 곳으로 갑니다.
화면을 누르면 서버 바탕화면에, 아래 입력창을 누르면 AI에 입력됩니다.

설정과 기록은 어디에 저장되나요?

~/Library/Application Support/MacAIterm/에 저장됩니다.
세션 기록은 설정에서 끄고 세션별로 삭제할 수 있습니다.
로컬 저장 내용은 개인정보 페이지에 정리했습니다.

MacAIterm을 삭제하려면?

앱을 종료하고 응용 프로그램에서 휴지통으로 옮기세요.
설정과 기록까지 지우려면 ~/Library/Application Support/MacAIterm/도 삭제하세요.
이 폴더를 지우면 로컬 데이터가 영구히 사라집니다.

MacAIterm은 무료인가요?

MacAIterm은 MIT 라이선스로 공개되어 있습니다.
고른 모델 제공자는 자체 서비스에 대해 별도로 요금을 받을 수 있습니다.
