설치

  1. 위의 .dmg를 내려받습니다.
  2. MacAIterm-0.1.0-arm64.dmg를 더블클릭해 엽니다.
  3. 창 안의 MacAIterm을 응용 프로그램 폴더로 끌어다 놓습니다.
  4. 디스크 이미지를 추출하고(Finder 사이드바의 ⏏), 응용 프로그램에서 MacAIterm을 우클릭 → 열기로 실행합니다.
  5. Ollama를 설치하고 모델을 받거나(예: ollama pull qwen3:8b), 다른 모델 옵션을 고릅니다.

다운로드 검증

터미널에서 아래 명령을 실행하세요.
결과가 위에 표시된 SHA-256과 일치해야 합니다.

shasum -a 256 ~/Downloads/MacAIterm-0.1.0-arm64.dmg

첫 실행

  • “열 수 없음” / “확인되지 않은 개발자”: Finder에서 앱을 우클릭 → 열기 → 열기.
    또는 시스템 설정 → 개인정보 보호 및 보안 → “그래도 열기”.
  • 그래도 막히면 터미널에서 한 번 실행하세요:
xattr -dr com.apple.quarantine /Applications/MacAIterm.app
  • Keychain 창: 서명하지 않은 앱을 설치하거나 업데이트하면 macOS가 “MacAIterm Safe Storage” Keychain 항목에 대해 묻습니다.
    비밀번호는 직접 입력하고 “항상 허용”을 고르세요.
    API 키를 저장하지 않는다면 거부해도 앱은 동작합니다.
  • “AI Terminal”에서 오셨다면: 앱의 예전 이름입니다.
    처음 실행할 때 설정, 탭, 기록, 저장한 SSH 세션이 새 데이터 폴더로 복사되고 옛 폴더는 그대로 남습니다.
    설정에 저장했던 API 키는 다시 입력해야 합니다.

FAQ

내 데이터는 어디로 가나요?

계정, 텔레메트리, 분석이 없습니다.
로컬 모델을 쓰면 대화와 명령 출력은 Mac 안에만 있습니다.
설정과 기록은 ~/Library/Application Support/MacAIterm에 저장됩니다.
OpenAI나 Codex를 고르면 대화가 그 제공자에게 전달됩니다.

SSH 비밀번호를 저장하나요?

아니요.
비밀번호와 키 암호는 터미널에서 직접 입력합니다.
저장된 세션에는 호스트, 사용자, 키 파일 경로만 있고 인증 정보는 없습니다.

어떻게 삭제하나요?

응용 프로그램의 MacAIterm을 휴지통으로 옮기세요.
데이터까지 지우려면 ~/Library/Application Support/MacAIterm도 삭제합니다.

변경 내역

버전 0.1.0

2026-10-05
  • 새 이름: MacAIterm(예전 이름 AI Terminal).
    처음 실행할 때 옛 데이터 폴더를 복사합니다.
  • SSH: 에이전트가 서버에서 작업(승인에 서버 이름 표시), 서버 CPU / 메모리 / GPU / 디스크 띠와 상태 패널, ~/.ssh/config 가져오기·점프 호스트·X11·포트 포워딩을 지원하는 세션 관리자, 끌어다 놓으면 복사하고 SHA-256으로 검증하는 서버와 Mac 파일 트리.
  • 상단 바의 Mac CPU 부하 표시, 더 큰 기본 창, 잘리지 않고 크기에 맞게 줄어드는 상단 바.
  • 탭, 분할 창, 세션 기록, 명령 블록, 프로세스 패널, 터미널 검색, 클릭할 수 있는 링크.
  • 플랜 모드, 스트리밍 답변, 프로젝트별 허용 규칙, 권한 모드, 감사 로그 내보내기.
  • OpenAI 호환 서버와 Codex CLI, API 토큰 사용량, 로컬 모델의 KV 캐시 절약.
  • vim 연동(:AitAI, LSP 진단), bash·fish 연동, 한국어·영어 인터페이스, 접근성 개선.

알려진 한계: 서명과 공증을 하지 않았습니다.
Intel 빌드는 제공하지 않습니다.
SSH는 로컬 테스트 서버, Ubuntu VM, NVIDIA DGX Spark 한 대(로그인과 모니터)에서 검증했고, 비밀번호 로그인만 되는 서버는 테스트하지 않았습니다.
