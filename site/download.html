Install

  1. Download the .dmg above.
  2. Double-click MacAIterm-0.1.0-arm64.dmg to open it.
  3. Drag MacAIterm onto the Applications folder in the window.
  4. Eject the disk image (⏏ in the Finder sidebar), then right-click → Open MacAIterm in Applications.
  5. Install Ollama and pull a model, for example ollama pull qwen3:8b, or choose another model option.

Verify the download

Run this command in a terminal.
The result must match the SHA-256 shown above.

shasum -a 256 ~/Downloads/MacAIterm-0.1.0-arm64.dmg

First launch

  • “Cannot be opened” / “unidentified developer”: in Finder, right-click the app → Open → Open.
    Or System Settings → Privacy & Security → “Open Anyway”.
  • If it is still blocked, run this once in a terminal:
xattr -dr com.apple.quarantine /Applications/MacAIterm.app
  • Keychain prompt: after installing or updating an unsigned app, macOS asks about the “MacAIterm Safe Storage” Keychain item.
    Type your password yourself and choose “Always Allow”.
    If you do not save API keys you can deny it; the app still works.
  • Coming from “AI Terminal”: the app used to have that name.
    On first launch your settings, tabs, history and saved SSH sessions are copied to the new data folder; the old one is left untouched.
    API keys saved in Settings must be entered again.

FAQ

Where does my data go?

There is no account, telemetry or analytics.
With a local model, conversations and command output stay on your Mac.
Settings and history live in ~/Library/Application Support/MacAIterm.
If you choose OpenAI or Codex, the conversation is sent to that provider.

Does it store my SSH password?

No.
You type passwords and key passphrases in the terminal.
A saved session holds the host, user and the path of a key file, nothing that authenticates.

How do I uninstall it?

Move MacAIterm from Applications to the Trash.
To remove its data too, delete ~/Library/Application Support/MacAIterm.
